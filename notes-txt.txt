Build me a personal budget tracking app called [APP NAME].

- Format all numbers as currency

DESIGN
[PICK ONE: clean and minimal / dark mode / colorful and playful]. Big readable numbers. It should feel like an app I'd pay for, not a spreadsheet.

# Build #2 — The Client Book

That first app was for YOU. This one is not. This one's for somebody else.

## What we're building and why

You'll drive past fifteen barbershops to get to YOUR barber. Because he knows your head. Your stylist is holding your whole hair history. A braider is keeping forty clients' patterns and part sizes in her memory.

So where does all that knowledge live? In their head. That's the whole system. No backup.

When the barber moves, or the stylist steps back for six months, or the shop changes hands — all of it walks out the door. None of that knowledge belongs to the SHOP. It belongs to whoever's standing behind the chair today.

We're building that shop a memory.

Every client gets a card. Photos of their last few cuts. The formula — guard numbers, colors, pattern. Notes like sensitive scalp, always ten minutes late, ask about his daughter. And when they last came in.

New barber starts Monday. Marcus walks in. Instead of twenty questions, the new guy taps Marcus's name and sees the last three cuts. "#2 on the sides, crisp line, leave the top." Marcus walks out thinking he's a mind reader.

Plus one screen just for the owner: everybody who hasn't been in for 45 days or more. Every quiet regular about to drift up the street, on one screen.

Four screens. You built four screens an hour ago.

Here's the exact workflow to get Sassy Spa v3 live on GitHub:
Step 1 — Create the Repo
Go to github.com/new and create a repo called sassy-spa. Don't initialize with a README (you already have one).
Step 2 — Push the Code
Unzip the file, then run these commands in your terminal:
bash
# 1. Unzip and enter the folder
unzip sassy-spa-v3.zip
cd sassy-spa-v3

# 2. Initialize git
git init
git add .
git commit -m "v3.0.0 — Sassy Spa Client Book with Bilt Rewards, GPS locations, marketing hub"

# 3. Connect to GitHub (replace YOUR_USERNAME)
git remote add origin https://github.com/YOUR_USERNAME/sassy-spa.git
git branch -M main
git push -u origin main
Step 3 — Enable GitHub Pages (Free Hosting)
In your repo on GitHub:
Go to Settings → Pages (left sidebar)
Under Build and deployment → Source, select GitHub Actions
Or if you want the simplest path: select Deploy from a branch → main → / (root)
But since this is a Vite app, you need a build step. Use this easier approach:
Option A: GitHub Actions (Recommended)
Create .github/workflows/deploy.yml in your repo:
yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [main]

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: 'pages'
  cancel-in-progress: true

jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
      - name: Set up Node
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'
      - name: Install dependencies
        run: npm ci
      - name: Build
        run: npm run build
      - name: Setup Pages
        uses: actions/configure-pages@v4
      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: './dist'
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
Then update vite.config.js to set the base path:
JavaScript
// vite.config.js — add the base line
export default defineConfig({
  base: '/sassy-spa/',  // ← ADD THIS (must match your repo name)
  plugins: [react()],
  // ... rest stays the same
})
Commit and push:
bash
git add .
git commit -m "Add GitHub Pages deploy workflow"
git push
Go to Actions tab in your repo, wait for the green checkmark, then visit:

Troubleshooting
Blank page after deploy?
You forgot base: '/sassy-spa/' in vite.config.js. Add it, commit, push.
404 on refresh?
GitHub Pages is static. For SPA routing, add a 404.html that redirects to index.html, or use HashRouter instead of BrowserRouter in main.jsx:
jsx
// Swap this in main.jsx for GitHub Pages
import { HashRouter } from 'react-router-dom'

<HashRouter>
  <App />
</HashRouter>
Images not loading?
The Picsum placeholder URLs work anywhere. If you swap to local images later, put them in public/ folder.
